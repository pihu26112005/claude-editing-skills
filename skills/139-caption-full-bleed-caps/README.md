## The style

A caption style built on scale. Each phrase gets one ultra-heavy condensed capital word in a single flat colour, stretched almost edge to edge along the top of the frame and tucked just behind the speaker's hair. Underneath, a tiny clean line fades in word by word, repeating the keyword in bold colour. On B-roll the giant word moves to the top edge or the bottom of the frame so it never fights the subject. Plain cuts, soft fades, no boxes.

Perfect for creator, tutorial, explainer and talking-head reels that want one loud word per beat.
