# 65 · Prompt Pill Reveal

## Results

**Your content, animated by Claude.** A brand pill opens into a prompt box, the request types itself and is sent, and a working pill bursts into a full result image; the demo uses a fictional tide-guide app with a generated seascape.

## The graphic

A brand name sits in a white rounded pill on a warm off-white canvas. The pill grows into a prompt box with a placeholder, small tool buttons and a coloured send button. The placeholder fades out and the user's request appears word by word, the box growing line by line. A pointer taps send, the box shrinks into a coloured pill with a spinning star and a status word that changes once, then folds into a small icon. The icon pops open into a result image with a caption, which settles and slowly pushes in.

Perfect for AI product teasers, app launch clips, "prompt to result" explainers and generator demos.

**Give it:**
- a brand name (up to 10 characters);
- your prompt text (up to 140 characters);
- a result image (any photo or artwork; it is cropped to 16:9) and a short caption;
- optional: placeholder, button labels, two status words, accent, background, text and caption colours.

**What you get back:** a finished 16:9 video (or a still image), rendered and checked by Claude.

**What's inside:**

- [description.md](description.md): the full specification: canvas, 13 parameters, every element and beat.
