## The graphic

A warm off-white page with a two-tone title and small column labels. Five rows rise in one after another, each with a rounded icon tile, a bold name, a dark role line and a grey reason line. A checkbox at the right of each row pops into a filled box and draws a white tick, one row at a time, while the camera drifts in very slowly.

Perfect for install steps, setup checklists, tool stacks, packing lists and progress screens.
