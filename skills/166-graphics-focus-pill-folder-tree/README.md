## The graphic

A white root card with a folder icon, a name and a sub-label sits on a soft light page, with a thin tree line and indented child folders below it. One folder gets a dark outlined pill while the others fade to grey. A new sub-folder appears as "untitled folder" and is renamed by typing, a file with a small thumbnail lands inside it, and a second sub-folder takes the pill. The camera drifts down to follow, then pulls back to show the whole tree.

Perfect for project structure explainers, workflow setups, file organisation tips and "how I organise my files" reels.
